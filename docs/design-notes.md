# 设计笔记

这份笔记记录一些“为什么这么做”的取舍，方便后来者（也包括未来的我）
理解代码背后的考量。

## 为什么坚持“核心可离线”

音频教学和快速排查经常发生在 SSH 到远程机器、或只有 CI 日志的场景里。
如果每次画图都要装 matplotlib、开 X11，门槛就太高了。所以：

- DSP 内核只用 NumPy（重采样用 SciPy），不碰绘图。
- 提供 ASCII 热力图 / sparkline，终端里直接看趋势。
- 连彩色图片导出都用内置的 PNG 编码器（仅 `zlib` + `struct`），
  不依赖 matplotlib 或 Pillow。

matplotlib 依然保留为可选后端，用于产出论文/报告级别的图。

## STFT 的形状约定

输出统一为 `(1 + n_fft // 2, n_frames)`，与 librosa 一致。这样做的好处是
生态里大量代码、教程可以直接对照，调试时也方便和 librosa 交叉验证
（测试里就有一条与 `scipy.signal.stft` 峰值位置对比的用例）。

## iSTFT 的重建

采用加窗重叠相加（WOLA），并用窗的平方和做归一化：

```
y[n] = Σ_m (frame_m[n - mH] · w[n - mH]) / Σ_m w²[n - mH]
```

在满足 COLA 条件的窗/跳距组合下（如 hann + 25% hop），可近似完美重建。
测试用相关系数 > 0.99 来验证，而不是逐点相等——因为边界帧和数值误差会带来
可忽略的偏差。

## 色度用“硬分配”而非三角加权

librosa 的色度滤波器组用了对数频率上的高斯加权和倍频程窗，实现相对复杂。
考虑到本项目偏教学，这里退一步：把每个 FFT bin 按最接近的十二平均律音级
硬分配到 12 个通道。

- 优点：实现直观、纯音能量集中、断言清晰（A4 → 音级 9）。
- 局限：对宽带信号不如加权版平滑。文档中明确标注为“简化实现”。

如果将来需要更平滑的色度，可以在 `chroma_filterbank` 里替换为加权矩阵，
上层 `chroma()` 无需改动。

## 数据类为什么关掉 `__eq__`

`Signal` / `Spectrogram` 是 `frozen` dataclass，字段里含 ndarray。dataclass
自动生成的 `__eq__` 会对数组做 `==`，得到布尔数组，再取真值时报
“ambiguous truth value”。与其埋雷，不如显式 `eq=False`，需要比较时由调用方
用 `np.allclose` 决定语义。
